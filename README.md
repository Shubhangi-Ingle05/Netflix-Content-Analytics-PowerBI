# 🎬 Netflix Content & Analytics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Netflix's content library.

The dashboard provides insights into:
- Movies vs TV Shows
- Content by country
- Top actors
- Content released over the years
- Movie duration
- TV show seasons
- Ratings and content types

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning

## 📌 Dashboard Features

### KPI Cards
- Total Titles
- Total Movies
- Total Cast
- Total Countries

### Visualizations
- Content by Type
- Top 10 Countries by Titles
- Top 10 Actors by Titles
- Titles by Release Year
- Movie Duration
- TV Show Seasons

### Filters
- Type
- Release Year
- Rating
- Country
